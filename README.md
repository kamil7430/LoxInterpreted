# Lox

A dynamically typed, interpreted language, implemented in C# (.NET 10). Result of Part II of [Crafting Interpreters](https://craftinginterpreters.com/) book. Credits to Robert Nystrom ;)

## Features

The language features [all the stuff covered in the book](https://craftinginterpreters.com/inheritance.html#conclusion). I have also done most of the Challenges, so there is a bit more than that. Lox features variables, functions, classes, inheritance, printing and most of the other basic stuff. There is a folder with example scripts to run.
